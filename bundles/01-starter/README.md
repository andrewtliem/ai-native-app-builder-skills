# Starter Bundle

**Purpose:** Move from raw idea to clear intent and a student-friendly PRD.

**When to use:** Use in Week 1 or before students commit to a project idea.

## Skills

| Skill | Role |
|---|---|
| [`grill-my-idea`](../../skills/grill-my-idea/SKILL.md) | Challenge the raw idea before PRD or coding. |
| [`idea-to-intent`](../../skills/idea-to-intent/SKILL.md) | Capture users, problem, constraints, tradeoffs, and success criteria. |
| [`intent-to-prd`](../../skills/intent-to-prd/SKILL.md) | Create a PRD with user stories, requirements, and acceptance criteria. |

## Outputs

```text
docs/ai-native/01-grill-my-idea.md
docs/ai-native/02-intent-brief.md
docs/ai-native/03-prd.md
```

## Student prompts

```text
Use grill-my-idea in classroom mode.
My app idea is: [idea].
Interview me one question at a time before I write a PRD. Do not suggest answers.
Save my answers verbatim to docs/ai-native/01-grill-my-idea.md.
```

```text
Use idea-to-intent.
Read docs/ai-native/01-grill-my-idea.md first.
Create an Intent Brief.
Save the output to docs/ai-native/02-intent-brief.md.
```

```text
Use intent-to-prd.
Read docs/ai-native/02-intent-brief.md first.
Create a PRD with user stories, FR IDs, SC IDs, acceptance criteria, non-goals, and risks.
Save the output to docs/ai-native/03-prd.md.
```

## Teacher checkpoint

Before moving on, the student should be able to answer:

- Who is the user?
- What problem is being solved?
- What is out of scope?
- What would prove the app works?

## Teaching Note

Students should run these skills one at a time, read the saved artifact, make a human decision, revise if needed, then continue. The bundle is a teaching path, not an autopilot.
